正方体折纸模拟器

把一张平面展开图沿着折痕折成正方体，全程可调、可回退、可随手标记。 用来讲清楚「展开图为什么能折成正方体」「哪个面折过去之后正对着哪个面」。

打开模拟器 返回首页

Features

把「纸面上的平面图」和「立体图形」放在同一个视角里。

6 种内置展开图

十字形、错开、阶梯、2-3-1、螺旋、长条，都是能折成正方体的合法展开图；也可以在 6×6 网格里自己拼一张，会即时校验能否折合。

折痕逐条控制

0°–90° 连续折叠，拖动滑杆看整张纸慢慢立起来；点折痕上的圆点可以只折一条，也可以「展开 / 折起 / 往复播放」。

相对面一目了然

点一个面，就高亮它的相对面；还可以给三组相对面各涂一色，或一键标成骰子（对面数字之和为 7），用来验证「相对面永不相邻」。

指定基准面

把某个面设成「正面」或「地面」，它在整个折叠过程中保持不动，其余五个面绕它收拢，方便对照课本上的折叠顺序。

画笔与印章

在纸面上自由作画、盖章、用橡皮擦修改，支持撤销与逐面清空。折起来之后，笔迹会跟着面一起转，看得见「图案转到哪一面去了」。

纯前端 · 单文件

一个 HTML 文件、零第三方依赖，手写投影把三维顶点画到 Canvas 上。没有后端、没有埋点，断网、离线、直接双击打开都能运行。

Controls

鼠标、触控板、手机触屏都能操作。

拖动画面旋转视角
滚轮 / 双指捏合缩放
点一个面选中，显示相对面
点折痕上的圆点只折这一条
双击空白处复位视角
右键（印章模式）印章旋转 90°
数字键 1–6快速选择印章
画笔模式按住面拖动即可作画

How it works

为什么看到的不是预先做好的动画。

立方体共有 11 种本质不同的展开图，这里收录了其中常见的 6 种，另外 5 种可以用自定义网格拼出来。 展开图以「面」为单位建模，每个面记录自身的 2D 坐标以及和相邻面之间的折痕方向。

折叠时先固定基准面，再按拓扑顺序让相邻面绕折痕轴旋转当前角度，最后把所有顶点用透视投影画到 Canvas 2D 上。 所以每一帧的形状都是按当前角度实时算出来的，滑杆停在哪，就画到哪。

笔迹保存在各个面自己的 2D 局部坐标系里，而不是贴在屏幕上，因此折起来时它会跟着面一起变换。

# 正方体折纸模拟器

一个纯前端的立方体折纸（展开图折叠）模拟器，静态托管于 GitHub Pages。

**在线访问：** https://buyu421.github.io/

## 站点结构

```
.
├── index.html            首页（项目介绍）
├── 404.html              自定义 404 页
├── assets/site.css       首页与 404 的样式
├── simulator/index.html  折纸模拟器（单文件应用，零依赖）
└── .nojekyll             跳过 Jekyll 处理，原样发布静态文件
```

`simulator/index.html` 是完全自包含的单文件应用：HTML、CSS、JavaScript 全部内联，
不引用任何外部资源，直接双击打开也能运行。

## 功能

- **6 种内置展开图**：十字形、错开、阶梯、2-3-1、螺旋、长条；另有 6×6 自定义网格，实时校验能否折成正方体。
- **折痕逐条控制**：0°–90° 连续折叠滑杆；点折痕圆点可单折一条；支持展开、折起、往复播放。
- **相对面**：选中面后高亮相对面，可给三组相对面各涂一色，或一键标注骰子（对面和为 7）。
- **基准面**：把某个面设为正面或地面，该面在整个折叠过程中保持不动。
- **画笔 / 橡皮 / 印章**：在纸面作画盖章，笔迹随面一起旋转，支持撤销与逐面清空。
- **视角**：拖动旋转、滚轮缩放、预设视角、自动旋转，双击空白处复位。

## 本地预览

任选一种方式，在仓库根目录执行：

```bash
# Python 3
python -m http.server 8123

# 或者 Node.js
npx serve .
```

然后打开 <http://localhost:8123/>。

因为不依赖构建步骤，也可以直接双击 `index.html` 打开。

## 部署

本站通过 GitHub Pages 从 `main` 分支根目录直接发布，无需 GitHub Actions。
修改后提交并推送即可，Pages 会在一两分钟内自动更新：

```bash
git add -A
git commit -m "更新站点"
git push
```

## 技术说明

展开图以「面」为单位建模，每个面记录自身的 2D 坐标与相邻面的折痕方向。
折叠时先固定基准面，再按拓扑顺序让相邻面绕折痕轴旋转当前角度，
所有顶点用透视投影画到 Canvas 2D 上；笔迹保存在各面自己的 2D 局部坐标系里，
因此会随面一起变换，而不是贴屏绘制。
